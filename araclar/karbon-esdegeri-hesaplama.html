FormülFormula

CE  = C + Mn/6 + (Cr+Mo+V)/5 + (Ni+Cu)/15
CET = C + (Mn+Mo)/10 + (Cr+Cu)/20 + Ni/40
Pcm = C + Si/30 + (Mn+Cu+Cr)/20 + Ni/60 + Mo/15 + V/10 + 5B

Standart referansıStandard reference

CE: IIW (1967); CET: EN 1011-2 Ek C (Yöntem B) / ISO/TR 17671-2; Pcm: Ito-Bessyo (JWES).CE: IIW (1967); CET: EN 1011-2 Annex C (Method B) / ISO/TR 17671-2; Pcm: Ito-Bessyo (JWES).

Geçerlilik aralığıValidity range

CET yalnızca C 0,05-0,32; Mn 0,5-1,9; Si ≤ 0,8; Cr ≤ 1,5; Ni ≤ 2,5; Mo ≤ 0,75; Cu ≤ 0,7; V ≤ 0,18 % aralığındaki çelikler için geçerlidir. Pcm genelde C ≤ 0,12 % olan düşük karbonlu çelikler için kullanılır.CET is valid only for steels with C 0.05-0.32; Mn 0.5-1.9; Si ≤ 0.8; Cr ≤ 1.5; Ni ≤ 2.5; Mo ≤ 0.75; Cu ≤ 0.7; V ≤ 0.18 %. Pcm is typically used for low-carbon steels (C ≤ 0.12 %).

Sık sorulan sorularFAQ

Karbon eşdeğeri nedir?What is carbon equivalent?

Alaşım elementlerinin sertleşebilirliğe etkisini karbon cinsinden ifade eden tek bir sayıdır; yüksek değer, ısıdan etkilenen bölgede sert yapı ve soğuk çatlama riskini artırır.A single number expressing the hardening effect of alloying elements in terms of carbon; higher values mean harder HAZ structures and a higher cold-cracking risk.

CE mi CET mi kullanmalıyım?Should I use CE or CET?

CE (IIW) genel kullanımlıdır; EN 1011-2 ön ısıtma yöntemi B için CET gerekir. Düşük karbonlu, mikro alaşımlı çeliklerde Pcm daha uygundur.CE (IIW) is general purpose; EN 1011-2 preheat method B requires CET. Pcm suits low-carbon, micro-alloyed steels.

CE hangi değerde ön ısıtma gerekir?At what CE is preheat needed?

Genel kural olarak CE > 0,40-0,45 olduğunda kalın kesitlerde ön ısıtma düşünülür; kesin değer kalınlık, hidrojen ve ısı girdisine bağlıdır (ön ısıtma hesaplayıcımıza bakın).As a rule of thumb preheat is considered above CE 0.40-0.45 on thick sections; the exact value depends on thickness, hydrogen and heat input (see our preheat calculator).
